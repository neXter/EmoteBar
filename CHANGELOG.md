# Changelog

All notable changes to EmoteBar are documented in this file.

## [1.8.1] - 2026-11-08

### Added

- New addon icon, shown in the in-game AddOn list (`Icons/EmoteBar.tga`).
- Square PNG versions of the icon for CurseForge, Wago.io, etc. (`docs/assets/icons/icon-512.png`, `docs/assets/icons/icon-400.png`).
- This changelog.

## [1.8.0] - 2026-11-05

### Added

- First public release.
- Movable, lockable bar of emote buttons.
- Custom icons per slot, with a bundled icon set.
- Horizontal or vertical layout, multiple rows/columns, adjustable scale (50–150%).
- In-game config window (`/eb`) and an entry under *Options > AddOns*.
- Settings saved across sessions (`EmoteBarDB`).
- English and German (deDE) text.
